Build the shortlist from software components

The roster combines server applications, instrument/control PCs, physical equipment, supplier services and hosted products. The deployment review identifies the assessment unit for every record.

Leadership implicationFilter by deployment type before comparing platforms. Equipment and supplier records require software mapping; their presence is not a compatibility failure.

02OEM and device constraints

Qualify control workstations separately

Roche’s 2020 Cedex addendum recommends its supplied control unit/image and limits other-hardware support. SCIEX validates its supplied PA800 controllers. Neither statement establishes a universal VM ban.

Leadership implicationConfirm the actual controller, software release, device interfaces and OEM terms. USB/serial connectivity alone does not prove that virtualization is prohibited.

03Explicit component boundaries

Distinguish an exclusion from a different deployment model

Cognex excludes two named Deep Learning 4.2 components from VMs. The BioTek 405 TS has onboard functions and optional PC software. A hosted core or container application creates a different infrastructure decision.

Leadership implicationApply exclusions only to the named release/component. Separate physical/onboard functions, PC software, containers and hosted cores rather than assigning a supplier-wide outcome.

04Platform and recovery qualification

Keep protection approval separate from hosting approval

Cohesity–VMware is published backup interoperability. Its HPE protection is guest-agent based; its Proxmox evidence is a repository / Remote Adapter workflow. Commvault and Acronis retain their own method restrictions.

Leadership implicationQualify the application/OEM stack and the backup/restore path as separate decisions. Published protection coverage does not approve application hosting.

Read the classifications and platform boundaries

Azure Local is separate from Hyper-V. Nutanix means AHV only in this matrix; Nutanix branding alone does not prove AHV. HPE refers to the HVM hypervisor. Oracle refers to OLVM / Oracle Linux KVM. Canonical MicroCloud / OpenStack requires the exact distribution to match. Citrix XenServer support does not establish XCP-ng support.

Named or conditional support still requires an installed-release and configuration match. The source register retains access limitations, historical evidence and document-identity conflicts. It does not certify the installed estate.
